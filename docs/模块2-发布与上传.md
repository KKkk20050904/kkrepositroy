## 四、接口文档

统一响应格式：成功 `{ "code": 0, "message": "xxx", "data": {} }`；失败 `{ "code": 4xx/5xx, "message": "原因" }`。

### 1. 图片上传

```
POST /api/upload
请求头：Authorization: Bearer <token>
请求体：multipart/form-data，字段名 files，最多 9 张，单张 ≤ 5MB，仅支持 jpg/png/gif/webp
```

响应示例：

```json
{ "code": 0, "message": "上传成功", "data": { "urls": ["/uploads/1793012812664-563059292.png"] } }
```

返回的 URL 是相对地址，配合静态目录直接访问：`http://localhost:3000/uploads/xxx.png`

### 2. 发布闲置商品

```
POST /api/goods
请求头：Authorization: Bearer <token>
请求体：application/json
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| title | string | 是 | 商品标题，≤ 50 字 |
| description | string | 否 | 商品描述，≤ 500 字 |
| price | number | 是 | 转让价格，> 0 |
| originalPrice | number | 否 | 原价 |
| categoryId | number | 否 | 分类 ID（见分类接口） |
| images | string[] | 是 | 图片地址数组，≤ 9 张，来自上传接口 |

```json
{
  "title": "九成新高数教材",
  "description": "教材二手转让，有少量笔记",
  "price": 15.5,
  "originalPrice": 59,
  "categoryId": 1,
  "images": ["/uploads/xxx.png"]
}
```

响应示例：

```json
{ "code": 0, "message": "发布成功", "data": { "id": 1 } }
```

### 3. 联调 token（开发用，登录模块完成后删除）

```
GET /api/dev/token
```

登录模块（张三）完成前，前端发布页打开时会自动调用本接口获取测试 token 并存入本地，之后的上传/发布请求自动携带，无需手动处理。

> 联调提示：登录模块完成后，删除 `routes/goods.js` 中的 `/dev/token` 路由，以及 `publish.vue` 中的 `ensureDevToken` 方法；前端改为登录成功后 `uni.setStorageSync('token', token)` 即可。

## 五、前端接入步骤（uniapp / HBuilderX）

> **现成工程（推荐）**：`E:\DoubaoWorkspace\campus-app` 已是一个完整的 uniapp 工程（首页 + 发布页 + 全部配置），直接用 HBuilderX 打开即可运行，见「九、HBuilderX 使用说明」。

### 4. 常见问题

| 现象 | 处理 |
| ---- | ---- |
| 首页提示「后端服务未连接」 | 后端没启动，先跑 `一键启动.bat`，再刷新浏览器 |
| 发布时提示「网络异常/请检查后端服务」 | 同上；确认 `E:\DoubaoWorkspace\campus-app\api\request.js` 里 BASE_URL 为 `http://localhost:3000/api` |
| 手机上预览（真机调试） | 手机与电脑连同一 WiFi，把 `request.js` 的 BASE_URL 改成电脑局域网 IP（如 `http://192.168.1.100:3000/api`），运行 → 运行到手机或扫码 |
| 微信小程序预览 | 需在 `manifest.json` 的 `mp-weixin.appid` 填你自己的小程序 AppID；H5/浏览器预览不需要 |
