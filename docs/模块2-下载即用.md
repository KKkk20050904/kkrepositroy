# 模块2：下载之后怎么把它跑起来

> 目标：**任何人从 GitHub 下载本项目，5 分钟内让「发布闲置商品 / 图片上传」跑通**，不需要改一行代码。
> 适用：验收前自测、组员联调、换电脑演示。

---

## 一、准备（装一次就够）

| 需要 | 版本 | 检查命令 |
|---|---|---|
| Node.js | 18 及以上 | `node -v` |
| MySQL | 5.7 / 8.0 | 服务里能看到 MySQL 在运行 |

> 网络较慢时，`npm install` 统一使用国内镜像：`--registry=https://registry.npmmirror.com`

## 二、三步启动

在**仓库根目录**（能看到 `server/`、`scripts/` 的那一层）执行：

```bash
# 第 1 步：装后端依赖
cd server
npm install --registry=https://registry.npmmirror.com
cd ..

# 第 2 步：建库 + 建表 + 分类种子（会自动生成 server/.env）
node scripts/setup-db.cjs

# 第 3 步：启动后端
cd server && node app.js
```

看到下面这行就成功了：

```
校园闲置交易后端已启动：http://localhost:3000
接口前缀：/api  健康检查：GET /api/health
```

浏览器打开 <http://127.0.0.1:3000/api/health>，返回 `{"code":0,"message":"ok",...}` 即正常。

### 或者：双击 `启动模块2.bat`

Windows 上直接双击仓库根目录的 `启动模块2.bat`，它会依次完成：装依赖 → 建库建表 → 启动后端 → 跑一遍接口自测。适合验收现场。

## 三、验证我的模块真的能用

```bash
node scripts/smoke-test.cjs     # 全链路：注册→登录→上传→发布→列表→详情→收藏→私信
node scripts/seed-goods.cjs     # 造 6 件示例商品（走真实发布接口，重复执行会自动跳过）
```

`smoke-test.cjs` 全部 `PASS`、退出码为 0，说明模块2的接口在这台机器上是好的。

也可以手动验证两个核心接口：

```bash
# 1) 上传图片（files 字段，最多 9 张，单张 ≤10MB，jpg/png/gif/webp）
curl -X POST http://127.0.0.1:3000/api/upload \
  -H "Authorization: Bearer <登录拿到的 token>" \
  -F "files=@test.png"
# → {"code":0,"data":{"urls":["/uploads/1794...png"]}}

# 2) 发布商品
curl -X POST http://127.0.0.1:3000/api/goods \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"title":"九成新高数教材","price":18.5,"originalPrice":46,"categoryId":1,"images":["/uploads/1794...png"]}'
# → {"code":0,"message":"发布成功","data":{"id":11}}
```

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ECONNREFUSED 127.0.0.1:3306` | MySQL 没启动 | 服务里启动 MySQL；或 `mysqld --datadir=<数据目录>` |
| `ER_ACCESS_DENIED_ERROR` | 密码不对 | 改 `server/.env` 的 `DB_PASSWORD`，或 `DB_PASSWORD=你的密码 node scripts/setup-db.cjs` |
| `ER_BAD_DB_ERROR` | 库没建 | 跑 `node scripts/setup-db.cjs` |
| `npm install` 卡住 / 超时 | 默认源被墙 | 加 `--registry=https://registry.npmmirror.com` |
| 端口被占用 | 已有实例在跑 | 关掉旧的黑窗口，或改 `server/.env` 的 `PORT` |
| 发布返回 `401` | 没带 token / token 过期 | 先 `POST /api/auth/login` 拿 token，7 天有效 |
| 分类出现两条「教材书籍」 | `init.sql` 的种子不是幂等的 | `setup-db.cjs` 会自动清理重复，或手动删多的那条 |

## 五、模块边界（谁负责什么）

| 接口 | 方法 | 负责 | 说明 |
|---|---|---|---|
| `/api/auth/register`、`/api/auth/login` | POST | 张三 | 发布前必须先登录，拿 JWT |
| `/api/upload` | POST | **李四（本模块）** | 多图上传，返回 URL 数组 |
| `/api/goods` | POST | **李四（本模块）** | 发布商品，写 `goods` + `goods_images` 两张表（事务） |
| `/api/goods`、`/api/goods/:id`、`/api/category` | GET | 王五 / 孙八 | 列表、详情、分类 |
| `/api/collect`、`/api/msg` | — | 赵六 / 钱七 | 收藏、私信 |

本模块的关键文件：

```
server/routes/goods.js              路由：POST /api/goods、POST /api/upload
server/controllers/goodsController.js  参数校验 + 事务写库 + 图片落盘
server/middleware/upload.js          multer：10MB 上限、5 种格式、时间戳文件名
server/middleware/auth.js            JWT 校验，把 userId 写进 req
server/sql/init.sql                  建库建表 + 分类种子
scripts/setup-db.cjs                 一键建库（本次新增，下载即用）
scripts/smoke-test.cjs               全链路自测
scripts/seed-goods.cjs              一键造 6 件示例商品
启动模块2.bat                        Windows 一键启动（本次新增）
```
