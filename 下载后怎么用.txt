校园闲置物品交易小程序 —— 下载后怎么用（Windows）
==========================================================

前提：一台 Windows 10 / 11 电脑，能上网。全程不用装开发工具。

第 1 步  装 Node.js（只装一次）
  打开 https://nodejs.org ，下载 LTS 版本，一路“下一步”装完。
  验证：按 Win+R 输入 cmd 回车，再输入  node -v  回车，能看到 v18 以上的版本号就行。

第 2 步  装 MySQL 8（只装一次）
  打开 https://dev.mysql.com/downloads/installer/ ，下载 MySQL Installer。
  安装时选 “MySQL Server”，Setup Type 选 “Server only”。
  设置 root 密码那一步填 123456（和项目默认一致，最省事）。
  验证：Win+R 输入 services.msc，列表里有 “MySQL80” 且状态是“正在运行”即可。

第 3 步  下载并解压项目
  GitHub 页面点绿色 Code 按钮 → Download ZIP，解压到一个路径里没有中文、没有空格的目录，
  例如 D:\campus 。解压后应该能看到：一键启动.bat、server、frontend、docs 这几项。

第 4 步  双击 一键启动.bat
  第一次会自动装依赖（大约 1 分钟），然后建库建表、写入 12 件示例商品，
  最后窗口里出现“校园闲置交易后端已启动：http://localhost:3000”就成功了。
  这个黑窗口就是服务本身，别关它。

第 5 步  打开浏览器
  访问 http://localhost:3000/api/goods ，能看到 12 件商品（带图片）就说明全部正常。
  也可以访问 http://localhost:3000/api/health ，返回 {"code":0,...} 同样说明正常。

怎么停止：直接关掉那个黑窗口。

----------------------------------------------------------
补充情况

· MySQL 密码不是 123456：
  在项目文件夹空白处按住 Shift 点右键 → “在此处打开 PowerShell 窗口”，执行
      set DB_PASSWORD=你的密码
  然后再双击 一键启动.bat 。

· 想看到网页界面（不是接口 JSON）：
  下载 HBuilderX（https://www.dcloud.io/hbuilderx.html），
  打开后“文件 → 导入 → 从本地目录导入”，选 frontend 目录，
  再点“运行 → 运行到浏览器”。

· 常见问题
  'node' 不是内部或外部命令        → Node 没装好，重装并重启电脑
  ECONNREFUSED / 数据库连接失败    → MySQL 没启动，去 services.msc 启动 MySQL80
  端口 3000 被占用                 → 关掉之前开着的黑窗口，或重启电脑后再双击
  中文显示乱码                     → 用资源管理器双击运行，不要用旧编辑器执行
  图片看不到                       → 正常应该能看到；若缺失，重新双击 一键启动.bat 会补上
